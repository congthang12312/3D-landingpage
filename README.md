# 3D Landing Pages

Modern 3D landing pages with React, Three.js, and Framer Motion.

## Projects

### 1. Kingsmen Barbershop
**URL:** `/` (root)

Chuyên nghiệp landing page cho tiệm cắt tóc nam với:
- 3D scissors animation
- Giới thiệu cửa hàng và câu chuyện
- Bảng giá dịch vụ với 3D cards
- Giới thiệu đội ngũ thợ cắt với 3D tilt effects
- Gallery với lightbox
- Booking form
- Map & contact info

**Theme:** Dark (đen, vàng gold, đỏ vintage)

## Quick Start

```bash
make
```

This will install dependencies and start the development server.

## Commands

| Command | Description |
|---------|-------------|
| `make setup` | Install dependencies |
| `make dev` | Start development server |
| `make build` | Build for production |
| `make preview` | Preview production build |
| `make clean` | Remove node_modules and build files |

## Tech Stack

- React 18 + TypeScript
- React Router DOM
- Three.js / React Three Fiber
- Framer Motion
- Tailwind CSS
- Vite

## Features

- Multiple 3D landing pages
- Client-side routing
- 3D interactive elements
- Smooth scroll animations
- Responsive design
- Glass morphism UI
- Contact forms
- Image galleries
- Booking system
